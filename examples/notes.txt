Ranker has no fallback :: when the model server times out the API just errors — there is no cheap path back to a popularity list.
Feature Store has no TTL :: come back after a few weeks and you still get stale features, so a cold start and a returning viewer look the same.
Impressions are fire-and-forget :: the client writes to Kafka with no retry, so a flaky network quietly drops a slice of the training data.
